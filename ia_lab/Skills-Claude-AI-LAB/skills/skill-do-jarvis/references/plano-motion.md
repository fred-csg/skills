# Plano de motion — catálogo frase → recurso

Cada frase da fala vira um visual. Usar como repertório, não como checklist: escolher o que casa com o sentido da frase.

## Aprovados no exemplo de referência (vídeo falado sobre IA e edição)
- "editar vídeo / VFX" → timeline de NLE atrás da cabeça com playhead + claquete 3D; "já era" → glitch + X vermelho + timeline caindo.
- Ano/número → numeral 3D gigante atrás da cabeça + punch + boom.
- "IA dominando" → rede neural desenhando no topo + chip AI 3D + card % subindo.
- "vídeos com IA" → cards de reels em profundidade com selo AI.
- "IA escuta" → microfone 3D + anéis saindo da boca (âncora) + waveform com a amplitude REAL da voz + chips FALA → TEXTO → CONTEXTO → IDEIA.
- "separa você / fundo" → linha de scan + contorno da silhueta + tag SUJEITO 99.4% + fundo escuro com grid + tag FUNDO.
- "elemento do seu lado" → ícones 3D surgindo ao redor com linhas tracejadas até a cabeça.
- "etapas / processo" → fluxo de nós acendendo em sequência com mini ícones 3D.
- "motion graphics" → título cinético gigante atrás da cabeça + fragmentos de UI, explodindo no impacto.
- "roteiro / pedir" → documento e prompt riscados + carimbo NÃO PRECISA.
- "IA entende" → retícula no rosto INTENÇÃO DETECTADA + checklist.
- "corte / respiro" → waveform com gaps RESP vermelhos que colapsam + tesoura 3D atravessando.
- Pergunta dramática → push-in + escurecer + interrogação 3D.
- "treinar IA / não sabe" → painel de treino + chips de modelos + barra despencando vermelha + DATASET 0 MB.
- "não vai funcionar" → alerta 3D + erro 404 zoeira; "não adianta" → cadeado 3D.
- "tá mudando" → foguete 3D atrás da cabeça + speed lines + chips 2024→2025→2026.
- "depender de outras pessoas" → cordas de marionete até a cabeça + chips SKILL DO FULANO.
- "não sair do lugar" → loading 0% "tempo estimado: nunca".
- "pronto / prompt" → botão gigante na cor de destaque + caixa de prompt digitando.
- "comentar prompt" → chuva de comentários + DM com arquivo + varinha 3D com faíscas; fecho com punch + glitch + carimbo zoeira.

## Genéricos
- Número/dado → count-up + barras/sparkline em card.
- Mostrou objeto/tela/pessoa → caixa de detecção, círculo à mão ou callouts (trackeados, ver `tracking.md`).
- Rosto/conteúdo gerado por IA → malha facial, grid "DEEPFAKE SCAN", mira, medidor IA% alto.
- Citou ferramenta/app → janela de UI (prompt digitando, botão, toast, player "✓✓ visto").
- Pedido/mensagem de cliente → inbox / balões de chat (entrada branca, saída no acento).
- Passos → checklist com ✓ ou chips acendendo em sequência.
- Negação ("sem X") → chips riscados em vermelho #FF4A3A.
- Silêncio/pausa dramática → "0 dB" linha reta + push lento.
- Conclusão → carimbo girado "ENTREGUE ✓" scale 2.2→1 + punch + shake.
- Palavra de impacto final → palavra gigante com glow + glitch + punch.
- CTA → pill "LINK AQUI EMBAIXO" pulsando + seta quicando + chip "VAGAS LIMITADAS".

## Zoeira (1 piada a cada ~8–10 s, sem poluir)
"BATERIA SOCIAL: 12%", "HUMANO REAL ✓ · sono 87%", "5 DEDOS ✓ (a IA aprendeu)", "RETINA: 100% IA · 0% alma", "VEÍCULO REAL · não é IA (juro)", animal como "SUPERVISOR · ATENTO", "NÍVEL DE BIZARRICE 100%", "SKILL DE EDIÇÃO NÃO ENCONTRADA", "SKILL DO FULANO / PRESET DO CICLANO", "VOCÊ ESTÁ AQUI (AINDA)", "SPOILER: NÃO VAI.".
Adaptar o tom ao usuário; se o vídeo for sério (saúde, luto, institucional), sem zoeira.
