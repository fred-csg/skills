# Nove arquiteturas de livro

Escolher pela lógica da transformação, não pelo prestígio do formato.

## 1. Problema–solução

Usar quando existe um problema específico. Progredir de diagnóstico e causas para solução, implementação e objeções. Evitar alongar a dor para manipular.

## 2. Método passo a passo

Usar quando há processo replicável. Apresentar visão geral, pré-requisitos, uma etapa por capítulo, integração e aplicação. Não chamar de proprietário sem base real.

## 3. Transformação narrativa

Usar quando a história sustenta a aprendizagem. Organizar antes, ruptura, busca, testes, descoberta, transformação e transferência ao leitor. Distinguir memória, reconstrução e documentação.

## 4. Manifesto

Usar para defender uma mudança de paradigma. Estruturar declaração, diagnóstico cultural, princípios, consequências, práticas e chamado. Sustentar provocações com argumento e evidência.

## 5. Lista progressiva

Usar quando capítulos são relativamente independentes. Criar uma ordem significativa: fundamento, alavancas, prática e síntese. Evitar coleção arbitrária de dicas.

## 6. Comparação

Usar para escolher entre abordagens ou expor trade-offs. Definir critérios equivalentes, comparar alternativas, mostrar contextos de adequação e propor decisão. Citar dados e evitar espantalhos.

## 7. Cronológica

Usar em história, evolução de campo, projeto ou trajetória. Organizar períodos, pontos de virada, causalidade, consequências e lições. Não confundir sequência temporal com causa.

## 8. Modular

Usar como manual de consulta. Criar módulos autônomos, rotas de leitura, referências cruzadas, glossário e índice forte. Reduzir dependências invisíveis entre capítulos.

## 9. Híbrida

Combinar no máximo duas lógicas dominantes, como narrativa + método ou problema–solução + modular. Declarar a função de cada parte e verificar se as transições preservam unidade.

## Matriz de escolha

| Condição dominante | Arquitetura provável |
|---|---|
| dor clara e solução | problema–solução |
| processo próprio | método |
| trajetória como prova | narrativa |
| mudança cultural | manifesto |
| ideias independentes | lista |
| alternativas concorrentes | comparação |
| evolução no tempo | cronológica |
| consulta não linear | modular |
| duas necessidades fortes | híbrida |

Sempre apresentar o custo da escolha: risco de repetição, lacuna de prova, complexidade ou expectativa criada no leitor.
