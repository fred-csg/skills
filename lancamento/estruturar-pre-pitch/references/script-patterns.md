# Padrões de roteiro

## Abertura

“Vamos fechar o raciocínio construído até aqui. Vimos [problema], entendemos [mecanismo] e agora vou conectar isso às opções práticas disponíveis.”

## Problema e consequência

“Os dados disponíveis mostram [achado]. Isso pode produzir [consequência] quando [condições]. O que os dados não permitem afirmar é [limitação].”

## Possibilidade

“Uma alternativa é [estado/processo]. Neste caso, [pessoa/equipe] obteve [resultado] após [processo], sob [condições]. O resultado não é uma garantia, mas o caso demonstra [ponto específico].”

## Ponte emoção → lógica

“Talvez essa possibilidade pareça relevante; agora precisamos verificar se ela é plausível. Vou mostrar o mecanismo, as evidências e os limites para você avaliar.”

Não afirmar “eu sei o que você está sentindo” ou antropomorfizar o “cérebro racional”.

## Prova

“A conta usa estas premissas: [A], [B] e [C]. Se alguma não se aplicar ao seu caso, o resultado muda. Aqui está a fórmula e um cenário conservador.”

## Adequação

“Este caminho tende a fazer sentido para [critérios]. Provavelmente não é adequado para [critérios]. Ele exige [tempo/esforço/recursos] e possui estes riscos e limites: [...].”

## Transição para oferta

“A parte de conteúdo termina aqui. Agora vou apresentar a oferta de [produto] para quem quiser implementar este processo com [tipo de apoio]. Vou mostrar preço, entregas, esforço, garantia e alternativas, para que você possa decidir se faz sentido.”

## Pergunta final

Preferir:

- “Quais informações você precisa para avaliar esta opção?”
- “Que parte do método ou da oferta ainda precisa ficar clara?”
- “Você quer conhecer a implementação acompanhada ou prefere encerrar com o plano que já recebeu?”

Evitar:

- “Você está pronto para parar de sofrer?”
- “Agora você só tem duas escolhas.”
- “Presta atenção porque sua vida vai mudar.”
- “Seu silêncio prova que isso tocou sua ferida.”
