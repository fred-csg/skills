# Orientação quando não houver pesquisa

Responder de forma acolhedora e direta, sem iniciar o perfil:

```markdown
Para extrair um perfil aspiracional confiável, preciso das respostas reais da pesquisa. Você pode anexar uma planilha ou documento, enviar um arquivo CSV/JSON/TXT/XLSX, ou colar as respostas aqui.

Envie, se possível:

1. As respostas da pesquisa de leads — item indispensável.
2. O produto ou serviço relacionado à pesquisa.
3. As perguntas originais do formulário ou entrevista.
4. O número total de respostas e eventuais filtros aplicados.
5. O contexto da audiência: origem, estágio do funil e dados demográficos relevantes, se coletados com consentimento.

Antes de enviar, remova dados pessoais desnecessários como nome completo, email, telefone, documentos e endereço. Se a planilha tiver muitas abas, indique qual contém as respostas.

Exemplo de uso:
`Use $extrair-perfil-aspiracional para analisar a pesquisa anexada. O produto é [produto], a audiência veio de [origem] e quero usar os achados para [objetivo].`

Com apenas as respostas já consigo começar; os demais itens aumentam a precisão.
```

Se o usuário enviar apenas perguntas sem respostas, explicar que é possível revisar o questionário, mas não extrair o perfil dos leads.
